# حاسبة الأرباح (Profit Calculator)

تطبيق بسيط وسريع جداً لحساب صافي الربح أو الخسارة بالمعادلة:
$$\text{النتيجة} = \text{المبلغ الأخير} - \text{كابيتال say} - \text{أرباح الشهر}$$

---

## 1. التشغيل الفوري والسريع (بدون تثبيت برامج)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح (على الكمبيوتر أو عبر الهاتف):
- يدعم الحساب اللحظي الفوري مع كل حرف يُكتب.
- يغير الألوان تلقائياً (أخضر للربح، أحمر للخسارة).
- يدعم جميع مقاسات الشاشات والهواتف.

## 2. مشروع الأندرويد Native (Android Studio)
المشروع موجود بالكامل في مجلد `android/`:
- مبرمج بلغة **Kotlin** مع **ViewBinding** و **Material Design 3**.
- مسار الكود: `android/app/src/main/java/com/example/profitcalculator/MainActivity.kt`
- لفتح المشروع وتوليد APK:
  1. افتح برنامج **Android Studio**.
  2. اختر **Open** ثم حدد مجلد `android`.
  3. اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)** لتوليد ملف الـ APK وتثبيته على هاتفك.
